# 웹게임파트 AX 담벼락

파트 내 AX 도구와 자동화 사례를 기록하고 공유하는 내부 게시판입니다.

---

## 주요 기능

### AX 기록하기
- **카테고리 분류**: 스킬 / 배포 / 자동화 중 선택
- **대상 지정**: 수강생, 전사, 팀, 파트, 트랙, 개인 복수 선택
- **상태 관리**: 기획 중 → 개발 중 → 홀딩 중 → 사용 중 → 사용 종료 / 폐기
- **배포 카테고리 전용**: 링크 + 웹페이지 스크린샷 미리보기 + 배포 플랫폼 입력
- **공통 필드**: 제목, 설명, 사용법 링크

### 담벼락 뷰
- **작성자별 섹션**: 구성원별로 카드 그룹핑, 본인 섹션이 항상 최상단
- **섹션 접기/펼치기**: 헤더 클릭으로 토글
- **드래그앤드롭**: 본인 카드만 드래그로 순서 변경, 저장됨
- **상태에 따른 카드 흐림**: 홀딩 중 / 사용 종료 / 폐기 카드는 자동으로 흐리게 표시
- **카드 배지**: 카테고리 + 상태 배지를 썸네일 위에 표시

### 검색 및 필터
- **통합 검색**: 헤더 검색창에서 이름 · 제목 실시간 필터링
- **사이드바 필터**: 카테고리 / 상태 / 대상별 필터 (복수 선택, 접기/펼치기 가능)
- **사이드바 구성원 필터**: 특정 구성원 카드만 보기

### 사용 신청 (하트)
- 다른 사람의 AX 도구에 **사용 신청** (본인 카드 신청 불가, 시도 시 안내 메시지)
- 신청 시 **하트 버스트 애니메이션** (카드 + 상세 모달 동일 적용)
- 신청 받으면 작성자에게 **알림 발송**
- **배포 고려 탭**: 신청 2개 이상인 항목만 모아서 표시
- **내 신청 탭**: 내가 신청한 항목만 모아서 표시

### 카드 상세 모달
- 웹페이지 스크린샷, 설명, 사용법 링크 표시
- 댓글 + 대댓글 (스레드 형식)
- 작성자 전용 `···` 메뉴: 수정 / 공지 설정 / 삭제
- **수정**: 카테고리, 상태, 대상, 링크 등 전체 필드 수정 가능
- **공지**: 활성화 시 카드 상단 배너 + 전체 페이지 상단 공지 배너 동시 표시
- 항상 화면 중앙에 고정 (스크롤 위치 무관)

### 알림
- 헤더 🔔 벨 아이콘 + 읽지 않은 수 빨간 배지
- 알림 발생: 내 카드에 댓글 / 대댓글 / 사용 신청, 방명록 @태그
- 알림 클릭: 해당 카드 상세 모달 즉시 오픈 (태그 알림은 방명록 패널 오픈)
- 개별 삭제 + 전체 읽음 처리
- 30초마다 자동 갱신

### 방명록
- 우측 하단 💬 버튼으로 채팅 형식 패널 오픈
- **@태그**: 입력 중 `@` 타이핑 시 구성원 자동완성 팝업
- 태그된 이름 파란색 하이라이트, 태그 시 해당 구성원에게 알림
- 본인 메시지 `···` 메뉴로 삭제

### 이모지 스티커
- 우측 하단 ⭐ 버튼으로 이모지 24종 팔레트 오픈
- 화면 어디든 붙이기, 드래그로 위치 이동, 스크롤과 함께 따라다님
- **실시간 동기화**: 한 사람이 붙이거나 이동하면 다른 구성원 화면에 즉시 반영
- 본인 스티커만 삭제 가능

### 프로필 · 구성원 관리
- 프로필 이미지 업로드 (아바타)
- 카드 색상 자유 선택 (이름 클릭 드롭다운에서 OS 기본 색상 피커)
- 구성원 등록: 이름 입력 (여러 명 줄바꿈으로 일괄 등록)
- 비밀번호 개인 변경 가능
- 로그인 유지 30일

### 기타
- 배경 이미지 + 반투명 흰색 패널 레이아웃
- 구성원별 고유 색상 (자동 할당 또는 직접 선택)
- 효승 프로필 왕관 👑
